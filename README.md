# Carnival of the Animals
This project is designed to engage primary school children through interactive English content, offering a personalized learning experience powered by artificial intelligence. The main objective is to analyze human-computer interaction behavior and provide a basic understanding of how Node.js works, including the management of handlers.

## Features

- **Interactive English Content**: Tailored activities and exercises to help children learn English in an engaging and fun way.
- **Artificial Intelligence Integration**: Personalized learning paths based on the behavior and needs of each student.
- **Human-Computer Interaction Analysis**: Captures and analyzes user behavior to improve the interactive experience.
- **Node.js Basics**: Demonstrates the fundamental workings of Node.js, including the use of handlers for managing functionality.

## Technology Stack

- **Node.js**: Backend JavaScript runtime for server-side functionality.
- **HTML, CSS, JavaScript**: Frontend technologies for building interactive user interfaces.
- **AI Toolkit**: Powered by artificial intelligence to adapt to the needs of users.
